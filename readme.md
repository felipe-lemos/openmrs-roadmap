A Gutenberg block plugin for displaying the OpenMRS product roadmap and timeline in a visually engaging way.

== Description ==

OpenMRS Roadmap provides a custom Gutenberg block to display a timeline or roadmap of OpenMRS product features, releases, or milestones. The block is fully compatible with the WordPress block editor and can be inserted into any post or page. It supports custom color schemes and is styled to match the OpenMRS design system.

**Features:**

- Custom "Roadmap/Timeline" block for the WordPress editor
- Visual timeline of releases, features, or milestones
- Color scheme support (teal, purple, orange, etc.)
- Responsive and accessible design
- Easy to use and configure

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/openmrs-roadmap` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. In the block editor, search for "OpenMRS Roadmap" or "Timeline" and insert the block into your page or post.

== Frequently Asked Questions ==

= How do I add a roadmap or timeline? =

After activating the plugin, open the WordPress block editor, search for "OpenMRS Roadmap" or "Timeline", and insert the block. You can then add and edit roadmap items directly in the editor.

= Can I customize the colors? =

Yes! The block supports multiple color schemes (teal, purple, orange, etc.) to match your site or OpenMRS branding.
